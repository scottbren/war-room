---
name: map-validator
description: Validates map data and explains failures in plain terms. Use after editing anything in packages/content/maps.
tools: Bash, Read, Grep, Glob
---
Run `pnpm validate-map`.

If it fails, explain each problem in plain terms: which room, door, cover object, or link is wrong, and what change would fix it. Keep it short. Do not edit the map yourself.
